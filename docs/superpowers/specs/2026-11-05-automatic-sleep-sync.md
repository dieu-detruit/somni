# Automatic sleep synchronization

User requested removal of repeated manual/night-specific imports and collection of all unsynced sleep records. Scope delegated for implementation.

- Share one iPhone HealthSleepReader across app lifecycle and history UI. On foreground, synchronize all readable sleepAnalysis additions/updates/deletions without selecting a night. Initial import has no arbitrary date cap. Prefer HKAnchoredObjectQuery with pagination and persisted secure-archived anchor plus raw samples, committed transactionally. Rebuild affected nightly summaries; retain raw daytime and morning intervals for export. Preserve source selection where valid. No fabricated stages or zero-sleep inference from missing permissions.
- Request read sleep authorization via an obvious connect/import button initially; for an existing authorization choice, foreground query may run automatically. Existing installations with cached sleep data should upgrade naturally. HealthKit does not reveal read authorization; request status is not read-grant status. Manual full refresh must recover historical data after permission changes (reset/rebuild anchor safely) without destroying valid stored data on failure.
- Observe HealthKit updates while app running, coalesce concurrent syncs and foreground events; do not promise execution while terminated. Foreground catch-up is required. Background entitlement/delivery optional only if properly configured/tested, not required for this release.
- Keep manual refresh as retry/recovery, not nightly requirement. Display last sync time and useful error/empty status. Show dates as evening-to-morning labels to avoid wrong-night selection. History picker includes imported nights, not just playback/rating dates or last seven days. Update Watch summary after successful save.
- Export retains synced full-resolution samples/coverage separately from old clipped caches; no external data uploads. Deletion clears synced records/anchor and stops auto reimport until explicitly reconnected, so delete-all does not immediately resurrect data. Preserve all legacy state fields through migration.
- Tests: additions/replacements/deletions/idempotence, multi-night/midnight intervals, daytime samples retained, source preservation, old state decode, failed save does not advance anchor, reset/reconnect semantics. Run Mac shared tests + iOS/watchOS archive and TestFlight distribution using this repository.
